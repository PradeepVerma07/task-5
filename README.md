# Comerica Web Banking – Login UI

Pixel-perfect frontend UI replication of the **Comerica Web Banking login page**.

## 📌 Scope
- UI only (no backend / authentication)
- HTML5, CSS3
- Minimal JavaScript (UI behavior only)
- Desktop-first layout (banking-style)
- Responsive background with fixed login card

## 🛠 Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Remix Icon

## ✨ Features
- Exact layout and spacing
- Focus states (2px black border)
- Password visibility toggle
- Login button activation state
- UI-only error message simulation
- Fixed-width login card (real banking behavior)
